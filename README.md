### About Me:
Hi, I'm Lokesh, a Computer Science undergraduate at IIIT Nagpur who enjoys building scalable backend systems and AI-powered applications. I work primarily with TypeScript, Node.js, Next.js, PostgreSQL, and Redis, and I'm interested in distributed systems, system design, and performance engineering.<br><br>I enjoy turning ideas into real, production-oriented projects and constantly exploring how to build software that's reliable, efficient, and easy to scale. Outside development, I'm an active competitive programmer with 500+ problems solved and a multiple-time hackathon and coding competition winner.<br>
